## Что это

Система не пытается угадать, какая буква в геноме изменится, — это принципиально невозможно. Вместо этого она решает четыре задачи, каждая из которых научно обоснована и измерима:

| Модуль | Вопрос | Выход |
|---|---|---|
| **GV-Resist** | Устойчив ли изолят к препарату? | Прогноз резистентности к 13 препаратам за 1–2 дня вместо ~60 |
| **GV-Escape** | Насколько опасна замена, если она возникнет? | Оценка риска для ещё не наблюдавшихся мутаций |
| **GV-Growth** | Вытесняет ли эта линия остальные? | Прогноз доли на 2–8 недель с интервалами |
| **GV-Sentinel** | Появилось ли что-то аномальное? | Раннее оповещение о необычных комбинациях |

**Главная метрика — Lead Time:** на сколько дней раньше система подаёт сигнал по сравнению с официальным признанием угрозы. Всегда отчитывается в паре с бюджетом ложных тревог.

## Целевые патогены

- ***Mycobacterium tuberculosis*** — лекарственная устойчивость. Приоритет №1: в Казахстане ~26 % новых случаев ТБ с МЛУ против 3,2 % в мире.
- **SARS-CoV-2** — иммунное ускользание, ретроспективная проверка Lead Time.
- ***Staphylococcus aureus*** (MRSA) — госпитальная передача и устойчивость.

## Данные

Гибридный пятислойный датасет: геномы (NCBI, GISAID, ENA) → эволюция (UniRef, ESM-2) → структура (PDB, AlphaFold DB) → фенотип (CRyPTIC 12 289 изолятов, каталог мутаций ВОЗ 2-е изд., DMS-карты Bloom lab) → эпидемиология (Nextstrain, WHO).

## Принципы

- Валидация только по времени и по кластерам родства — никакого случайного разделения выборки.
- Аугментация только после разделения и только в обучающей части.
- Обязательные baseline, калиброванные вероятности, доверительные интервалы метрик.
- Модель обязана уметь ответить «нет заключения».
- Данные пациентов не покидают периметр учреждения.

## Статус

Исследовательский инструмент (research use only). Не является сертифицированным медицинским изделием. Не ставит диагноз и не назначает лечение.
