Формат определяется по содержимому и направляется своей модели: варианты — на прогноз лекарственной устойчивости, последовательности белка — на ранжирование мутаций по эволюционному риску, счётчики линий — на прогноз динамики. Результат скачивается таблицами для дальнейшего анализа.

Данные не покидают этот компьютер. Приложение работает локально: файлы разбираются и анализируются здесь же, никуда не отправляются и не сохраняются.
