GERMOVISIONMutation Intelligence

Mutations arise at random.
They survive predictably.

GermoVision does not try to say which mutation will appear next — that is a random event and nobody can forecast it. It answers the questions that can be answered: what a mutation does to treatment, whether evolution will keep it, and how fast the lineage carrying it is displacing the others.

What it answers

Will this treatment work?

Resistance called from the genome for 13 drugs, in about two days after sequencing instead of the roughly 60 days a culture-based test takes.

Which substitutions matter?

Every substitution ranked by evolutionary risk — including ones that have not appeared yet, which is what makes the warning early.

What is spreading, and where?

Growth advantage per lineage per region, with intervals that widen where less was sequenced instead of pretending to precision.

The four models

What you can feed it

Format is detected from file contents, not from the extension, and routed to the model that fits. A whole genome is refused on purpose: assembly and variant calling are a separate pipeline with their own failure modes.

How it is validated

Checked automatically on every run; a violation stops the run rather than producing a better-looking number.

  1. Split by time, never at random. Uses submission date, not collection date: a sample collected on 1 November but deposited on the 20th was not available to the system on the 5th.
  2. Relatedness clusters stay intact. Isolates from one outbreak are near-identical and are not independent observations.
  3. External geographic validation. Train on 22 countries, test on the 23rd.
  4. Augmentation only after the split, only on train. A CI test fails if the order is reversed.
  5. Feature vocabulary built from train alone. Collecting it over all data is a quiet leak.
  6. Calibration on a separate part that overlaps neither training nor test.
  7. Baselines are mandatory. The reference is the standard in use today — the WHO catalogue — not random guessing.

Where it must not be trusted alone

Stated here because a system that hides its limits gets used past them.

  1. It does not diagnose or prescribe. It supplies information for a clinician's decision.
  2. It does not predict when a mutation will appear. Mutation is a random event; its consequences and its fate are what can be predicted.
  3. Poorly characterised drugs stay weak. Bedaquiline, delamanid and linezolid carry a lab-confirmation flag that reaches the clinical report.
  4. It degrades over time. The pathogen evolves; without retraining the estimates go stale.
  5. Research use only. Not a certified medical device.

Run it on your own machine

Analysis is local by design. Uploading sequences would send patient data to a server, so the published build offers no upload at all.

pip install -e ".[app]"
python -m germovision.train --save-models models
python -m germovision.app
