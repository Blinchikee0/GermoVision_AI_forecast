Что происходит в регионах

GV-Growth · мультиномиальная логистическая модель

Результат секвенирования — счётчики: из N образцов за неделю столько-то относятся к каждой линии. Доли связаны условием нормировки, а неопределённость зависит от объёма выборки, поэтому динамика описывается мультиномиальной моделью, а не регрессией по каждой линии отдельно. Коэффициент β — логарифмическое преимущество роста за неделю, величина с прямым биологическим смыслом.

Насколько можно доверять выводам

GV-Resist · внешняя валидация

Показаны результаты внешней валидации: модель обучена без единого изолята из Казахстана и проверена на них. Это единственная оценка, отражающая реальное развёртывание — внутренний тест всегда оптимистичнее. Точка отсчёта не «случайное угадывание», а действующий стандарт: применение каталога мутаций ВОЗ.

Чувствительность по препаратам

Чувствительность — доля выявленных устойчивых изолятов. Пропуск устойчивости означает назначение неработающей схемы, поэтому именно эта метрика ведущая.

Цена отказа от ответа

Система может ответить «нет заключения» и отправить образец на фенотипический тест. Кривая показывает, что при этом выигрывается.

Точка на кривой — выбор организации, а не разработчика: сколько образцов она готова отправлять на подтверждение. Рабочая настройка отмечена крупным маркером.

Столбец «Фенотип» — результат лабораторного теста, полученный позже и использованный только для проверки. В работе врач его на этот момент ещё не имеет: в этом и состоит выигрыш во времени.

Границы применимости

  • Система не ставит диагноз и не назначает лечение — она предоставляет информацию для решения врача.
  • Не предсказывает дату возникновения мутации: мутация — случайное событие, предсказуемы её последствия и судьба.
  • Для препаратов с плохо изученными механизмами устойчивости (бедаквилин, деламанид, линезолид) чувствительность заметно ниже — это видно на графике и прямо указывается в выдаче.
  • Не заменяет фенотипическое тестирование там, где оно обязательно по протоколу.
  • Качество деградирует со временем: возбудитель эволюционирует, и без переобучения оценки устаревают.
  • Статус: исследовательский инструмент. Не является сертифицированным медицинским изделием.

Как получены цифры

  • Разделение выборки по времени, кластеры родства не разорваны: близкородственные изоляты не являются независимыми наблюдениями.
  • Словарь признаков построен только по обучающей части; калибровка — на отдельной выборке, не пересекающейся ни с обучением, ни с тестом.
  • Доверительные интервалы — стратифицированный бутстрэп, 500 выборок.
  • Отказ от ответа реализован через конформное предсказание с гарантией покрытия.
